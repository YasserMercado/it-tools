# IT Automation Utilities

A small collection of personal scripts to automate everyday tasks in macOS and Linux. Built while learning Python, Bash, and system administration.

---

## 🛠️ Tools Included

### 1. Capitalize Directory Names (Python)
* **File:** `upperDir.py`
* **Description:** A simple Python script that scans the current folder, finds all subdirectories, and renames them so that the first letter is uppercase and the rest remains unchanged.
* **How to run:**
  ```bash
  python3 upperDir.py

### 2. Network Diagnostics Script (Python)
* **File:** `testNetUnix.py`
* **Description:** A simple Python script designed for Unix/macOS environments that sequentially executes key network diagnostic commands—including active IPv4 interface filtering, default gateway resolution, packet reachability checks, and network route tracing.
* **How to run:**
  ```bash
  python3 testNetUnix.py
